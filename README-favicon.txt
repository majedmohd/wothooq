أيقونة موقع وثوق — طريقة الرفع على GitHub
==========================================

المحتويات:
  index.html            ← نسخة موقعك بعد إضافة وسوم الأيقونة (تستبدل القديمة)
  favicon.ico           ← 16/32/48 بكسل — الأساسي
  favicon.svg           ← نسخة فيكتور (أوضح على الشاشات عالية الدقة)
  favicon-96x96.png     ← المطلوب لظهور الأيقونة في بحث قوقل
  favicon-16x16.png
  favicon-32x32.png
  favicon-48x48.png
  favicon-192x192.png   ← أندرويد / إضافة للشاشة الرئيسية
  favicon-512x512.png
  apple-touch-icon.png  ← 180x180 لأجهزة آيفون/آيباد
  site.webmanifest

الخطوات:
1) ارفع كل هذي الملفات في **نفس المجلد** الذي فيه index.html داخل المستودع
   (عادة جذر المستودع، أو مجلد /docs إذا كنت مفعّل GitHub Pages منه).
2) استبدل index.html القديم بهذا (الوسوم مضافة تحت <title> مباشرة).
3) Commit ثم انتظر دقيقة إلى دقيقتين حتى ينشر GitHub Pages التحديث.

ملاحظات:
- المسارات نسبية (بدون / في البداية) عشان تشتغل سواء كان الموقع على
  دومين مستقل أو على رابط مشروع مثل username.github.io/wathooq/
- إذا ما تغيّرت الأيقونة في المتصفح: Ctrl+Shift+R، أو افتح رابط
  الأيقونة مباشرة مرة واحدة (المتصفحات تخزّنها بعناد).
- لظهورها في نتائج قوقل: تحتاج زيارة جديدة من Googlebot. اطلب فهرسة
  الصفحة الرئيسية من Google Search Console لتسريعها.
